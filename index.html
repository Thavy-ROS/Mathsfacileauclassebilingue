📘 Le second degré

Objectif : Comprendre les fonctions du second degré, calculer leurs racines et étudier leur représentation graphique.

1. Définition

Une fonction du second degré est une fonction qui peut s'écrire sous la forme :

f(x) = ax² + bx + c

Avec :

  • a, b et c sont des nombres réels.
  • a ≠ 0.
  • x est la variable.

Exemple : f(x) = 2x² + 3x - 5

2. Le discriminant (Delta)

Pour résoudre une équation du second degré :

ax² + bx + c = 0

On calcule le discriminant :

Δ = b² - 4ac

Le discriminant permet de connaître le nombre de solutions.

3. Les solutions de l'équation

Premier cas : Δ > 0

L'équation possède deux solutions réelles distinctes.

x₁ = (-b - √Δ) / 2a

x₂ = (-b + √Δ) / 2a

Deuxième cas : Δ = 0

L'équation possède une solution réelle double.

x₀ = -b / 2a

Troisième cas : Δ < 0

L'équation ne possède aucune solution réelle.

4. Le sommet de la parabole

La représentation graphique d'une fonction du second degré est une parabole.

Le sommet S a pour coordonnées :

α = -b / 2a

β = -Δ / 4a

Donc : S(α ; β)

Si a est positif, la parabole est tournée vers le haut.

Si a est négatif, la parabole est tournée vers le bas.

5. Exemple d'application

Résoudre : x² - 5x + 6 = 0

Étape 1 : Identifier les coefficients.

a = 1 ; b = -5 ; c = 6

Étape 2 : Calculer le discriminant.

Δ = (-5)² - 4 × 1 × 6

Δ = 25 - 24 = 1

Étape 3 : Calculer les solutions.

x₁ = (5 - 1) / 2 = 2

x₂ = (5 + 1) / 2 = 3

Conclusion : les deux solutions sont 2 et 3.

6. À retenir

  • Forme développée : ax² + bx + c.
  • Discriminant : Δ = b² - 4ac.
  • Si Δ > 0 : deux solutions.
  • Si Δ = 0 : une solution double.
  • Si Δ < 0 : aucune solution réelle.
  • La courbe représentative est une parabole.

💡 Petit conseil

Pour réussir les exercices sur le second degré, commence toujours par identifier les coefficients a, b et c, puis calcule le discriminant.

Les équations

Une équation est une égalité qui contient une inconnue.

Exemple : x + 3 = 7

On soustrait 3 des deux côtés.

x = 7 - 3 = 4

La solution est x = 4.
